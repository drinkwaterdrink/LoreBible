## Clarifications, not dropped requirements

- Secrets do not become earned merely because selective keys or recursion match. Unsupported revelation state stays explicit and gated.
- A full-world package is an artifact composition, not a mandatory single-card template.
- Project directory files are a portable archive option; transactional records avoid multiple writable copies of the same fact.
- QA, provenance, build records, and minimal IR start earlier than the original phase headings imply.
- Native advanced fields/modules require contemporary fixtures. Internal planning support does not imply export support.
- Health percentages require defined measurements; model judgments stay qualitative or clearly labeled.
- Source Studio, art, and advanced mechanics remain optional for small original-fiction projects.
- Long-term capacity does not justify regenerating accepted content, adding unrelated motifs, or forcing maximum entry counts.
